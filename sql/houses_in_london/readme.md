# #1. Imóveis em Londres

✅ Objetivo: Realizar análise exploratória dos dados para responder perguntas usando SQL dentro do ambiente JupyterLab.

✅ Conjunto de dados: O conjunto de dados foi obtido por meio de um dataset disponível no [Kaggle](https://www.kaggle.com/datasets/oktayrdeki/houses-in-london/data), 
sendo um compilado de dados que contém várias características e informações de preço sobre casas em Londres.

📍**Perguntas em foco:** 

**1. Qual é o preço médio dos imóveis por bairro?**

**2. Quais são os imóveis com mais de 3 quartos e mais de 2 banheiros?**

**3. Quais imóveis possuem garagem e jardim ao mesmo tempo?**

**4. Qual bairro tem o maior número de imóveis renovados?**

**5. Quais tipos de aquecimento são mais comuns para imóveis com varanda?**

**6. Quais imóveis têm vista para o mar e preço acima de £2.000.000?**

**7. Qual a distribuição do número de andares dos imóveis em cada bairro?**

**8. Quais bairros têm a maior proporção de casas com aquecimento elétrico?**

**9. Qual a distribução de status de imóveis e idade por bairro?**

**10. Buscando imóveis em Notting Hill.**

🏆 Com a integração de SQL no JupyterLab foi possível realizar a manipulação dos dados utilizando técnicas de filtragem, agregação e classificação para consultar e responder as perguntas propostas sobre a distribuição de imóveis e suas caracteristicas. Além das habilidades técnicas de manipulação de dados, ficou claro que a interpretação crítica dos dados e a identificação das perguntas-chave a serem respondidas são cruciais para uma análise de qualidade.

Além disso, a compreensão do perfil dos dados e a especificidade das informações desempenham um papel essencial na escolha das abordagens corretas para análise. A capacidade de conectar os insights extraídos com as necessidades do negócio é fundamental para maximizar o valor da análise. Esse processo não apenas melhora a tomada de decisão, mas também direciona ações mais estratégicas dentro do contexto do mercado
